# মাই ব্যাংক (MyBank) — ঋণ আবেদন ও অ্যাডমিন ম্যানেজমেন্ট সিস্টেম
## MyBank Bangladesh — Digital Loan Application & Staff Management Portal

একটি ফুল-স্ট্যাক লোন ম্যানেজমেন্ট অ্যাপ্লিকেশন (Next.js 16 + React 18 + Tailwind CSS, Supabase Auth ও PostgreSQL)।

> **নোট:** "MyBank" একটি কাল্পনিক (fictional) ব্র্যান্ড, কোনো প্রকৃত ব্যাংক বা প্রতিষ্ঠান নয়। এই সিস্টেম ঋণ প্রদান ও পরিশোধ ট্র্যাক করে — ঋণ পাওয়ার শর্ত হিসেবে গ্রাহকের কাছ থেকে কোনো ফি নেয় না, এবং পুলিশ/সরকার/অন্য ব্যাংকের নামে কোনো ডকুমেন্ট তৈরি করে না।

---

### 🚀 যেভাবে রান করবেন (How to Run)

১. প্রজেক্ট ফোল্ডারে যান:
```bash
cd h:\loan
```

২. প্রথমবার ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```

৪. ব্রাউজারে প্রবেশ করুন:
- **গ্রাহক পোর্টাল (Customer Portal):** [http://localhost:3000/login](http://localhost:3000/login)
- **নতুন রেজিস্ট্রেশন:** [http://localhost:3000/register](http://localhost:3000/register)
- **সুরক্ষিত স্টাফ/অ্যাডমিন লগইন:** [http://localhost:3000/staff/login](http://localhost:3000/staff/login)
- **স্টাফ ড্যাশবোর্ড:** [http://localhost:3000/staff](http://localhost:3000/staff)

---

### 🔐 Supabase সেটআপ

প্রথমবার চালানোর আগে [Supabase সেটআপ গাইড](supabase/SETUP.md) অনুসরণ করুন। এতে SQL migration চালানো, email/password authentication চালু করা, স্টাফ অ্যাকাউন্ট অনুমোদন এবং deployment environment variables যোগ করার ধাপ আছে। কোনো ডিফল্ট `admin/admin123` অ্যাকাউন্ট নেই; স্টাফ অ্যাকাউন্ট Supabase-এ তৈরি ও অনুমোদিত করতে হবে।

---

### 🌟 ফিচারসমূহ (Features)

1. **Supabase PostgreSQL:** গ্রাহক, প্রোফাইল, লোন ও বার্তা স্থায়ীভাবে সংরক্ষণ হয়; Row Level Security প্রতিটি রেকর্ডের প্রবেশ নিয়ন্ত্রণ করে।

2. **পাসওয়ার্ড-প্রোটেক্টেড স্টাফ ড্যাশবোর্ড (`/staff/login`):** অননুমোদিত প্রবেশ স্বয়ংক্রিয়ভাবে লগইন পেজে রিডাইরেক্ট হয়; সঠিক অ্যাডমিন ক্রেডেনশিয়াল ছাড়া ড্যাশবোর্ড খোলা যায় না।

3. **মাল্টি-স্টেপ KYC:** ব্যক্তিগত তথ্য, রক্তের গ্রুপ, NID (সামনে/পেছনে), গ্রাহকের ছবি ও ক্যানভাসে আঁকা ডিজিটাল স্বাক্ষর।

4. **নমিনী ও পেআউট অ্যাকাউন্ট:** নমিনীর তথ্য এবং বিকাশ/নগদ/রকেট/ব্যাংক অ্যাকাউন্ট নির্বাচন।

5. **লাইভ EMI ক্যালকুলেটর:** ৳ ৫০,০০০ – ৳ ২০,০০,০০০ পর্যন্ত, ১২–৬০ মাস মেয়াদে; বার্ষিক ফ্ল্যাট ২.৪% সুদে (Total = Principal + Principal × Tenure/12 × 0.024)।

6. **ডায়নামিক ইউজার ড্যাশবোর্ড:** আবেদন জমা দেওয়ার পর ইন্টারফেস অ্যাক্টিভ ড্যাশবোর্ডে রূপান্তরিত হয় — মোট ঋণ, উত্তোলনযোগ্য ব্যালেন্স, মাসিক কিস্তি ও লাইভ স্ট্যাটাস।

7. **স্টাফ অ্যাডমিন প্যানেল:** ডাটাবেজ থেকে **বাস্তব** পরিসংখ্যান (মোট/অনুমোদিত/পেন্ডিং/বাতিল), সার্চ ও সর্ট, স্ট্যাটাস আপডেট, ব্যালেন্স এডিট, এবং লোন ডিলিট।

8. **তথ্যমূলক মেসেজিং (Informational only):** স্টাফ গ্রাহককে স্ট্যাটাস আপডেট / কাগজপত্রের অনুরোধ / কিস্তি অনুস্মারক পাঠাতে পারে। কোনো ফি বা "পরিশোধ করুন" অপশন নেই।

9. **ঋণদাতার নিজস্ব ডকুমেন্ট জেনারেটর:** শুধুমাত্র তিনটি — Loan Approval Letter, Repayment Schedule, ও Disbursement Advice (MyBank ব্র্যান্ডিং, প্রিন্ট/PDF সহ)।

---

### 🚀 লাইভ ডেপ্লয়

Supabase migration এবং email/password Auth সেটআপ শেষ করে Vercel-এ `NEXT_PUBLIC_SUPABASE_URL` ও `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` যোগ করুন, তারপর GitHub repository deploy করুন। `data/db.json`-এর পুরোনো স্থানীয় তথ্য স্বয়ংক্রিয়ভাবে স্থানান্তরিত হবে না; নিরাপদভাবে নতুন অ্যাকাউন্ট তৈরি করুন এবং বাস্তব গ্রাহকের তথ্য ব্যবহারের আগে access policies পরীক্ষা করুন।
